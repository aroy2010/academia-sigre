# Créditos y Desarrollo

El **Sistema de Gestión de Residentado (SIGRE)** y esta plataforma de documentación (Academia SIGRE) representan un esfuerzo de modernización y transformación digital impulsado desde el interior del Instituto Nacional Cardiovascular (INCOR).

---

## 👨‍⚕️ Autoría y Desarrollo

Este sistema fue conceptualizado, diseñado y programado íntegramente por:

* **Dr. Adriel Olórtegui Yzú**
* Médico Asistente de la Oficina de Apoyo a la Investigación y Docencia Especializada (OAIYDE).
* *Instituto Nacional Cardiovascular "Carlos Alberto Peschiera Carrillo" - EsSalud.*

> [!info] Visión del Proyecto
> El SIGRE nace con el objetivo de optimizar los tiempos administrativos, transparentar la asignación de campos clínicos y garantizar una evaluación oportuna y justa para todos los médicos residentes que pasan por nuestra institución.

---

## 💻 Tecnologías Utilizadas

Para garantizar un ecosistema robusto, de costo cero y alta disponibilidad, el SIGRE y su documentación han sido construidos sobre las siguientes tecnologías:

### El Sistema Principal (SIGRE)
-   :fontawesome-brands-google: **Google Workspace:** Base de datos construida sobre Google Sheets para asegurar la portabilidad y seguridad de los datos institucionales.
-   :fontawesome-brands-js: **Google Apps Script (GAS):** Lenguaje de programación backend (basado en JavaScript) que procesa las reglas de negocio, el envío de correos y la seguridad.
-   :fontawesome-brands-bootstrap: **Bootstrap & HTML5:** Framework de diseño utilizado para crear las interfaces de usuario web responsivas (Frontend).

### La Academia SIGRE (Manuales)
-   :fontawesome-solid-pen-nib: **Obsidian:** Entorno de redacción y gestión del conocimiento en formato Markdown (`.md`).
-   :fontawesome-solid-cube: **MkDocs Material:** Generador de sitios web estáticos que transforma los archivos de texto en esta plataforma interactiva.
-   :fontawesome-brands-github: **GitHub Pages:** Servidor de alojamiento gratuito y control de versiones que mantiene esta documentación en línea 24/7.
