# Tutoriales por Módulo

Este archivo reúne una versión resumida de los tutoriales de SIGRE. El contenido completo, con pasos extendidos y errores comunes, se mantiene en el manual principal.

## Módulos cubiertos

1. Disponibilidad
2. Consulta de Trámite
3. Registro de Solicitud
4. Registro / Actualización de Perfil
5. Login y recuperación de contraseña
6. Evaluación de Residentes
7. Gestión de Respuestas
8. Generación de Hojas de Evaluación
9. Plan de Trabajo
10. Monitoreo de Evaluaciones
11. Estadísticas del Programa
12. Gestión de Usuarios
13. Asignación de Roles
14. Privilegios de Acceso
15. Configuración del Sistema

## Estructura recomendada para cada tutorial

- Objetivo de aprendizaje
- Requisitos previos
- Paso a paso detallado
- Resultado esperado
- Errores comunes y cómo solucionarlos

## Recomendación editorial

Si este documento se usa en MKDocs, cada tutorial puede exportarse como una página individual o permanecer en este archivo como sección desplegable por módulos.
