# Versión para Google Docs

Este archivo contiene la versión simplificada del manual SIGRE para copiar y pegar en Google Docs.

## Recomendaciones de uso

- Conservar títulos y subtítulos tal como aparecen aquí.
- Sustituir los bloques Mermaid por capturas de pantalla o figuras exportadas.
- Mantener saltos de sección entre cada capítulo para facilitar la lectura.
- Usar esta versión como base para impresión, validación editorial o distribución interna.

## Estructura sugerida

1. Portada
2. Presentación
3. Diagramas del sistema
4. Guías por tipo de usuario
5. Tutoriales por módulo
6. Preguntas frecuentes
7. Glosario

## Observación

Para Google Docs, los diagramas Mermaid pueden reemplazarse por imágenes exportadas desde MKDocs o por diagramas en formato PNG/SVG.
